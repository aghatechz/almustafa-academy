# Al-Mustafa Academy Pakistan 🎓

A modern, high-performance web application for **Al-Mustafa Academy Pakistan**, built using **Next.js (App Router)**, **TypeScript**, **Tailwind CSS**, and **Framer Motion**.

---

## 🌟 Key Features

- 🛥️ **Unified Floating Dock Navbar:** Modern single-capsule navigation bar with seamless logo integration, pill hover effects, active state tracking, and responsive mobile drawer.
- 🎬 **Hero Section Canvas:** Custom notched rounded card layout featuring HD background video, dark royal blue gradient overlay, and high contrast typography.
- 🔄 **Infinite Ticker Marquee:** Docked bottom cutout pill displaying scrolling Academy pillars (*Youth Tarbiyat*, *Academic Excellence*, *Leadership Workshops*, *Community Mentorship*).
- 🎨 **Brand Palette:** Primary Royal Blue (`#0B3888`), Accent Sky Blue (`#00A3E0`), and Pure White (`#FFFFFF`).
- ⚡ **Performance & Accessibility:** Server-rendered layout, zero hydration warnings, and optimized video playback.

---

## 🛠️ Tech Stack

- **Framework:** Next.js 16 (App Router with Turbopack)
- **Language:** TypeScript 5
- **Styling:** Tailwind CSS 4 & Vanilla CSS
- **Animations:** Framer Motion 13
- **Icons:** Lucide React

---

## 🚀 Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 📦 Build for Production

To create an optimized production build:

```bash
npm run build
npm run start
```
